# thio.cc.cd — Flessan (M. Thio Saputra)

Welcome! This is the repository for the personal website of
**Flessan (M. Thio Saputra)** at [thio.cc.cd](https://thio.cc.cd).

The site covers his work and world: [GDIPS](https://gdips.pages.dev) (the
open-source, community-driven Geometry Dash Indonesia Private Server), the
project rack, the "internet of Thio" ecosystem, writing, a `/now` page, a
timeline, and ways to connect and support the work.

**Deployed on Cloudflare Pages.**

## Stack

- [VitePress](https://vitepress.dev) + Vue 3 — static build, no server runtime needed
- Custom theme on top of the VitePress default theme
  (Plus Jakarta Sans · JetBrains Mono · Flessan red / charcoal / TAKO blue)
- Cloudflare Pages serving: static assets, pretty URLs, `_redirects`, `_headers`

## Requirements

- Node.js **22** (pinned in `.nvmrc`; Cloudflare Pages picks this up automatically)
- pnpm **10** (pinned via `packageManager` in `package.json`)

## Local development

```
pnpm install
pnpm run dev
```

Then open the local URL printed in the terminal.

## Build

```
pnpm run build
```

Outputs the static site to **`.vitepress/dist`**.

To preview the production build with real Cloudflare Pages semantics
(`_redirects`, `_headers`, pretty URLs, `404.html`):

```
pnpm run build
pnpm run preview:pages    # npx wrangler pages dev .vitepress/dist
```

## Deploy to Cloudflare Pages

### Option A — Git integration (recommended)

1. In the Cloudflare dashboard: **Workers & Pages → Create → Pages →
   Connect to Git**, and select this repository.
2. Set the build configuration:
   - **Build command:** `pnpm run build`
   - **Build output directory:** `.vitepress/dist`
3. Node and pnpm versions come from `.nvmrc` and `packageManager`, so no
   environment variables are needed. (You can also set `NODE_VERSION=22` in
   the dashboard under *Settings → Environment variables* if you prefer.)
4. Every push to your production branch deploys automatically; every other
   branch gets a preview deployment at `<hash>.<project>.pages.dev`.

### Option B — Wrangler CLI (direct upload)

```
npx wrangler login
npx wrangler pages project create thio-cc-cd --production-branch=main
pnpm run deploy
```

`pnpm run deploy` builds the site and runs
`npx wrangler pages deploy .vitepress/dist --project-name=thio-cc-cd`.
(If you created a project with a different name, pass that name instead.)

### Custom domain

In the Pages project: **Settings → Custom domains → Set up a custom domain**,
add `thio.cc.cd` as a CNAME to `<project>.pages.dev`. Domains on Cloudflare
DNS are verified automatically — exactly like his other Pages deployments
(`flessan.pages.dev`, `gdips.pages.dev`, `tune.thio.cc.cd`…).

## Cloudflare Pages configuration files

| File | Purpose |
| --- | --- |
| `public/_redirects` | Shortlinks (`/gh` → GitHub, `/sponsor` → GitHub Sponsors, `/discord`, `/gdps`, `/yt`, `/wa`, …). Copied into the deploy root. |
| `public/_headers` | `Cache-Control: immutable` for hashed `/assets/*`, one-week cache for `/images/*`, plus baseline security headers. |
| `.nvmrc` | Pins Node 22 for the Pages build environment. |
| `404.html` | Generated by VitePress; Pages serves it automatically for unknown paths. |

Cloudflare Pages also serves pretty URLs natively — `about.html` is served at
`/about`, which matches the site's `cleanUrls` setting and the sitemap.

### Subdomain redirects (optional)

`_redirects` can only match paths, not hostnames. If you want the old
subdomain shortcuts (e.g. `gh.thio.cc.cd` → GitHub), attach the subdomains to
the Pages project or add **Redirect Rules** in the Cloudflare dashboard:

| Host | Destination |
| --- | --- |
| `gh.` / `github.` / `git.thio.cc.cd` | https://github.com/flessan |
| `gdips.thio.cc.cd` | https://gdips.pages.dev |
| `ig.thio.cc.cd` | https://www.instagram.com/flethio |
| `threads.thio.cc.cd` | https://www.threads.com/flethio |
| `yt.thio.cc.cd` | https://youtube.com/@flethio |
| `sponsor.thio.cc.cd` | https://github.com/sponsors/flessan |
